# Zafarmand visual references

These files are the visual targets supplied for the Zafarmand website:

- `zafarmand-navigation-prototype.gif` demonstrates the navigation flow. It is
  kept locally and ignored by Git because it is a 47.7 MiB design artifact.
- `zafarmand-home.jpg` shows the homepage composition.
- `zafarmand-products.jpg` shows the products-page direction.
- `zafarmand-interior-design.jpg` shows the interior-design direction.
- `zafarmand-architecture-design.jpg` shows the architecture-design direction.

They are design references, not production page images. Text, navigation controls,
sample projects, and the `NORM ARCHITECTS` identity are baked into the files.
The public website should recreate the relevant layout with accessible HTML, CSS,
real routes, and clean final media rather than displaying these screenshots as
the interface.

The prototype also uses `/product`; the website's canonical route remains
`/products`.
